<objective>
Declutter the New Block editor (`fitbod/Periodization/BlockBuilderView.swift`) by replacing
the inline stepper controls in `NewBlockMetricsBand` with tappable read-only value cells that open
two new editor sheets, and removing the redundant APPLY PRESET button from the phases header.

brief is already shipped (STARTING POINT band removed, bottom PRESETS routes to the full

ONLY remaining work is D1 (weeks), D2 (days), D3 (header trim), the wiring/cleanup, and the
single required test edit. DO NOT modify ProgramView.swift.

Purpose: Move per-phase week editing and days selection into focused sheets so the main screen
reads as display-only summary cells, matching the brutalist value-cell aesthetic and reducing
on-screen stepper clutter.
Output: Updated `BlockBuilderView.swift` (two new inline fileprivate sheet structs, restructured
metrics band, trimmed phases header, removed dead adjust helpers) and one deleted obsolete test
assertion.
