The footer body (struct NewBlockBottomActionBar, lines ~1890-1941) currently ends with:

  .padding(.horizontal, NewBlockScreenTokens.screenMargin)
  .padding(.top, 10)
  .padding(.bottom, 8)
  .background(NewBlockScreenTokens.paper.ignoresSafeArea(edges: .bottom))

The `.padding(.top, 10)` is the lever that pushes the buttons down. Increasing it adds
breathing room ABOVE the buttons (between the last scrolled phase card and the footer).

The scroll content reserves bottom clearance via this token (line ~325-326):

  // 260528-vi2: bumped 60 -> 72 to clear the new taller bottom bar (52pt button + ~20pt padding)
  static let bottomActionHeight: CGFloat  = 72

CRITICAL: `bottomActionHeight` is the spacer the LazyVStack reserves at the foot of the
scroll so phase cards do not scroll UNDER the bar. The bar's intrinsic height is approximately
top padding + 52pt button + bottom padding. If you increase `.padding(.top`, the bar grows
taller, so `bottomActionHeight` MUST grow by the same delta or scrolled cards will collide
with / peek above the footer.
