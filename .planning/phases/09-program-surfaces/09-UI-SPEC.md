## Surface Specifications

### 1. ProgramView — BLOCKS section

**Trigger:** `Block.count > 0 || Split.count > 0` — if false, show existing NoProgramHero + ProgramTemplateSection (locked, guardrail-pinned).

**Layout:**
```
BRUSectionHead("Blocks", right: nil)
ForEach blocks ordered: ACTIVE first, then READY, then DRAFT, then DONE
  BlockStatusCard(block:)
  BRUDivider(.hair)  ← between cards
BRUDivider(.ink)    ← section bottom boundary
```

**BlockStatusCard anatomy (top to bottom, 16pt h-pad, 12pt v-pad):**
```
HStack:
  BRUChip(derivedStatus.label, color: ..., fill: ...)  ← per badge table above
  Spacer()
  [ACTIVE only] Text("W{N} · {phase}") .labelSmall .uppercase .tracking(1.2) bruMuted

Text(block.name) .bodyEmphasis bruInk
[ACTIVE only] Text("Week {N} of {M} · {phase}") .bodyDefault bruMuted  ← single line

[DONE section] Only show 3 most recent. "ALL HISTORY ▸" disclosure row below:
  Text("ALL HISTORY ▸") .labelSmall .uppercase .tracking(1.2) .bruSignal
  on tap: reveal full DONE list (inline expansion, no navigation)
```

Tap the entire card → push `BlockOverviewRoute.summary(blockID:)` into `navigationPath`.
`.contentShape(Rectangle())` on card. 44pt minimum height.

**DONE collapse behavior:**
- Default: show 3 most recent DONE blocks.
- `@State private var showAllDone = false`.
- "ALL HISTORY ▸" row: `labelSmall`, signal color, tap → `showAllDone = true`, row disappears.
- No animation on expansion per reduced-motion check; default animation otherwise (`.animation(.easeOut, value: showAllDone)`).
- Accessibility: `.accessibilityLabel("Show all \(doneCount) completed blocks")` on the disclosure row.

### 2. ProgramView — ROUTINES section

```
BRUSectionHead("Routines", right: nil)
ForEach splits (non-archived, sorted by name):
  RoutineSplitRow(split:)
  BRUDivider(.hair)
BRUDivider(.ink)
```

**RoutineSplitRow anatomy (16pt h-pad, 12pt v-pad, 44pt min height):**
```
HStack(spacing: 12):
  VStack(alignment: .leading, spacing: 4):
    Text(split.name) .bodyEmphasis bruInk
    Text("{sessionCount} sessions") .bodyDefault bruMuted
  Spacer()
  UsageTagFlow(tags: liveNonCompletedBlockNames)   ← wrapping horizontal flow
  Text("›") .bodyEmphasis bruMuted
```

**UsageTagFlow:** Uses `ProgramChipFlow` layout (existing in `ProgramView.swift`) with `UsageTagChip` items. Each chip: `BRUChip(blockName)` outline (no fill), `labelSmall`, tracking +1.2, UPPERCASE. Renders nothing if `liveBlockEdges.isEmpty` (clean row — no "unused" label).

Tap → push `SplitDetailRoute` (new route enum) onto `navigationPath`.

**"+ NEW ROUTINE" action:** Appended as last item before section bottom divider — `BRUSectionHead`-style row with right-aligned `Text("+ NEW ROUTINE")` in `bruSignal` `labelSmall`. On tap → `presentingNewRoutine = true` (existing sheet). Decision: placing the add action as a dedicated row (not inside section head right slot) keeps the section head accessible and leaves the right slot free for future count metadata.

### 3. SplitDetailView (new screen)

**Navigation:** Pushed via `ProgramRoute.splitDetail(splitID: UUID)`. Owns no child NavigationStack — uses ProgramView's stack.

**Header:**
```
BRUHeaderBar.slots(
  left: .back,
  center: "Routine · {split.name}",
  right: .action("ARCHIVE", archiveAction)
)
```
Archive action routes through `BlockLifecycleService.assertSplitDeletable`. If denied → present error sheet (see Destructive Actions).

**Live-edit banner:** Shown when `split.blocks` contains any active block.
```
LiveEditBanner(message: "Part of active block — edits apply to upcoming workouts.")
```
Positioned immediately below `BRUHeaderBar`, above `ScrollView`. Non-blocking (no dismiss button).

**Slot section:**
```
BRUSectionHead("Sessions", right: "+ ADD SESSION", rightAction: { presentingSlotPicker = true })
ForEach orderedSlots:
  SplitSlotRow(slot: slot, onRemove: removeSlot)
  BRUDivider(.hair)
BRUDivider(.ink)
```

**SplitSlotRow anatomy (16pt h-pad, 44pt min height):**
```
HStack(spacing: 12):
  Text("\(slot.position + 1)")  .labelSmall .uppercase .tracking(1.2) bruMuted  ← 32pt wide
  Text(slot.sessionTemplate?.name ?? "—")  .bodyEmphasis bruInk
  Spacer()
  // drag handle — ⠿ unicode braille dots (not SF Symbol)
  Text("⠿")  .bodyEmphasis bruMuted  .accessibilityHidden(true)
```

**Drag reorder:** Hysteresis-gated, row-local `@GestureState` offset pattern (reuse New Block phase-card drag precedent, not `List .onMove`). Reduced-motion: disable drag animation (`@Environment(\.accessibilityReduceMotion)`), allow drop still. Reindex-on-write: positions become `0..<n` contiguous after every reorder, add, or remove. Decision: not `List .onMove` because `List` styling violates BRU contract (adds system separators, background, etc.).

**Slot picker sheet:** `RoutineBuilderView` existing sheet flow, or a picker over all `SessionTemplate`s + "New session" option → `RoutineBuilderView`. Presented as `.sheet`. Sheet uses `.presentationDetents([.medium, .large])` for discoverability.

**Remove slot:** Swipe trailing `.swipeActions` → confirm alert "Remove Session?" / "Remove Session" (destructive) / "Cancel". Removal triggers reindex-on-write.

**Usage section:**
```
BRUSectionHead("Used in", right: nil)
if liveBlocks.isEmpty:
  Text("Not linked to any active block.")  .bodyDefault bruMuted  16pt h-pad 12pt v-pad
else:
  ForEach liveNonCompletedBlocks:
    HStack: Text(block.name) .bodyEmphasis bruInk  Spacer  BRUChip(block.derivedStatus.label)
    BRUDivider(.hair)
BRUDivider(.ink)
```

**Archive action deny error surface:** When `assertSplitDeletable` throws `BlockLifecycleError`, present `.alert` with title "Cannot Archive Routine" and message "This routine is linked to an active or upcoming block. End or complete that block first." Single "OK" button (`.cancel` role). Decision: alert (not sheet) — single dismissable error is appropriate; no recovery path needed.

### 4. BlockOverviewScreen — Live modes (draft/ready/active) extensions

Existing `BlockOverviewScreen` gains these elements beyond Phase 4.1's read-only view:

**Split attach/swap band** (shown on draft/ready status only — hidden on active):
```
BRUSectionHead("Routine", right: nil)
HStack(spacing: 12):
  if block.split == nil:
    BRUButton("+ ATTACH ROUTINE ▸", kind: .ghost) { presentingSplitPicker = true }
  else:
    Text(block.split!.name) .bodyEmphasis bruInk
    Spacer()
    Button("SWAP ▸") ...  .labelSmall .bruSignal
BRUDivider(.ink)
```
Decision: attach as full-width ghost BRUButton; swap as inline signal text-button (space-efficient, lower prominence than primary attach action).

**Mode picker** (shown on all live statuses):
```
BRUSectionHead("Scheduling", right: nil)
HStack:  // Segmented-style pair of outline chips
  ModeChip("ROTATION", selected: block.schedulingMode == .rotation)
  ModeChip("FIXED WEEKLY", selected: block.schedulingMode == .fixedWeekly)
```
`ModeChip`: `BRUChip`-derived — selected = ink fill + paper text; unselected = outline + ink text. Tap → `TrainingDaysWriter.sort` + save (write via service, not direct field). Decision: chip pair (not SwiftUI Picker) preserves BRU contract (no `.pickerStyle` chrome).

**Day-chip grid** (shown only when `schedulingMode == .fixedWeekly`):
```
BRUSectionHead("Training days", right: nil)
HStack(spacing: 4):  // 7 equal-width chips: M T W T F S S
  ForEach weekdays:
    DayToggleChip(letter, selected: trainingDays.contains(weekday))
```
`DayToggleChip`: 28pt height, equal flexible width. Selected = bruInk fill + bruPaper text + 1.5pt bruInk border. Unselected = bruFaint fill + bruMuted text + 1pt bruInk border. Tap → toggle weekday in `trainingDays` → `TrainingDaysWriter.sort(weekdays:using:)` → save.

**Soft mismatch hint** (shown below day-chip grid when `trainingDays.count != split.slots?.count ?? 0`):
```
Text("{trainingDays.count} days / {slotCount} sessions")
  .bodyDefault .Color.bruAmber  .padding(.horizontal, 16) .padding(.top, 4)
```
No icon. Decision: amber text, no chip, no border — "soft" = informational, not blocking.

**Start CTA** (shown when `derivedStatus == .ready`):
```
BRUButton("START BLOCK ▸", kind: .signal) { onStartTapped() }
  ← pinned to bottom, above BRUSafeAreaFiller, 2pt bruInk top rule
```
Tap → if another block is active, present `SwapConfirmSheet`; otherwise `BlockLifecycleService.start`.

**End action** (shown when `derivedStatus == .active`):
```
// Overflow menu item or secondary ghost button in bottom bar
BRUButton("END BLOCK", kind: .ghost) { presentingEndConfirm = true }
```
Below primary "EDIT BLOCK ▸" button (existing). End confirm: `.alert` "End block?" / "End Block" (`.destructive`) / "Cancel" — matching existing `BlockCard` alert copy.

**Swap Confirm Sheet copy (verbatim from spec §4):**
Title: `"Start Block?"`
Body: `"Ends *{currentBlock.name}* — its config freezes to history."`  (SwiftUI Markdown bold)
CTA: `BRUButton("Confirm", kind: .signal)`
Secondary: `BRUButton("Cancel", kind: .ghost)`

## Interaction Contracts

### Drag reorder (SplitSlotRow)

- Gesture: `DragGesture(minimumDistance: 8)` — hysteresis threshold matches New Block phase-card drag (June 10 perf work).
- Visual during drag: dragged row renders at +4pt vertical offset from touch, 0.95 scale, `bruBg2` background fill (slightly recessed vs `bruPaper`). Other rows shift with `.animation(.interactiveSpring, value: dragState)`.
- Drop: reindex-on-write — `positions` becomes `0..<n` contiguous, `ctx.save()` called once.
- Reduced motion: drag gesture disabled. List rows remain reorderable via an "Edit" mode toggle (future; v1 reduced-motion: show informational text "Reorder unavailable with Reduce Motion enabled" in `bodyDefault bruMuted`).
- Accessibility: `AccessibilityAction(.moveUp)` and `.moveDown` on each row so VoiceOver users can reorder without drag gesture.

### Collapse (DONE blocks)

- State: `@State private var showAllDone = false`.
- Default animation: `.animation(.easeOut(duration: 0.2), value: showAllDone)`.
- Reduced motion: no animation, instant swap.

### Mode chip toggle (ROTATION / FIXED WEEKLY)

- Tap: immediate visual toggle + `TrainingDaysWriter.sort(weekdays:using:)` + `ctx.save()`.
- Switching from `.fixedWeekly` to `.rotation`: clears `trainingDays` from UI display (field remains for potential re-toggle but day-chip grid is hidden).
- Switching from `.rotation` to `.fixedWeekly`: shows day-chip grid with `trainingDays` as last written (or empty).

### Day-chip toggle

- Tap: toggles weekday presence in local draft, then `TrainingDaysWriter.sort(weekdays:using:)` + save on every tap.
- Multiple taps rapid: each tap writes; no debounce needed (local-only, no network).
- Accessibility: `Toggle(day, isOn: binding)` trait so VoiceOver announces on/off state.

### Block start flow

```
User taps "START BLOCK ▸"
  → if another block is active:
      present SwapConfirmSheet (modal .sheet, .presentationDetents([.fraction(0.4)]))
      on "Confirm" → BlockLifecycleService.start(block, using: ctx)
      on "Cancel"  → dismiss sheet
  → else:
      BlockLifecycleService.start(block, using: ctx) directly
```
