<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| View → BlockLifecycleService | All isActive/endDate/archive/split mutations go through the service, never direct field writes |
| View → archive decode | Completed blocks render from decoded archive only; decode failure is terminal (no live fallback) |
| View → TrainingDaysWriter | trainingDays writes only via `TrainingDaysWriter.sort` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-09 | Elevation | Split swap/attach on active block | mitigate | Attach/Swap UI hidden unless `derivedStatus` is .draft/.ready; service also refuses (.splitChangeOnActiveBlock) as defense-in-depth |
| T-09-10 | Tampering | trainingDays written ad-hoc (unsorted) | mitigate | Every day/mode write goes through `TrainingDaysWriter.sort`; copy/source pin asserts the call |
| T-09-11 | Spoofing | Archive decode failure falling back to live template | mitigate | On `decodeArchive` throw, render `ArchiveUnreadableView`; never read live `block.split`. Copy pin asserts the error heading; no live-template read in the completed branch |
| T-09-12 | Tampering | Start without confirm while another block active | mitigate | If another isActive block exists, present SwapConfirmSheet (verbatim copy) before `BlockLifecycleService.start` |
</threat_model>
