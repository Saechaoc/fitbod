<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| View → SwiftData store | Slot CRUD writes positions; contiguity is a test invariant, not a schema constraint (no `#Unique` on (split, position)) |
| View → BlockLifecycleService | Archive must route through the single deny seam, never inline block-count checks |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-01 | Tampering | Slot reorder/add/remove | mitigate | Reindex-on-write renumbers positions 0..<n in one `ctx.save()`; `SplitDetailViewTests` asserts contiguity after each op (a dup position would silently merge rows — see SplitSessionSlot comment) |
| T-09-02 | Elevation | Archive bypassing deny seam | mitigate | Archive action calls `BlockLifecycleService.assertSplitDeletable`; on throw, present deny alert. No inline `split.blocks` count check used for the gate. |
| T-09-03 | Tampering | Hard-deleting a slotted SessionTemplate | mitigate | "Remove" deletes the `SplitSessionSlot` only (`ctx.delete(slot)`), never the `SessionTemplate` (`.deny` rule). Test asserts SessionTemplate survives removal. |
</threat_model>
