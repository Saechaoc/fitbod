## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| @Query → view ordering | `derivedStatus` is computed (not stored); status grouping/ordering must post-filter in Swift, never in #Predicate |
| Navigation push → destination | A pushed route with no registered destination silently no-ops (Pitfall 1) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-04 | Denial of Service | BLOCKS card tap with unregistered route | mitigate | Register `navigationDestination(for: BlockOverviewRoute.self)` on ProgramView's stack before BLOCKS taps; ProgramViewFidelityTests asserts the registration string is present |
| T-09-05 | Tampering | Predicate using computed `derivedStatus` | mitigate | @Query plain (or stored-attribute filter only); status ordering + usage tags via Swift post-filter; documented in code comment |
| T-09-06 | Information Disclosure | Usage tags showing completed (dead) block refs | mitigate | Usage tags filter `derivedStatus != .completed` only (live edges) — test/source pin |
</threat_model>
