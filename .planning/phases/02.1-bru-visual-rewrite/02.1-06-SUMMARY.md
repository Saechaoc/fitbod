# Phase 2.1 Plan 06: RoutinesListView BRU Visual Rewrite Summary

BRU brutalist composition replacing navigationTitle+List+toolbar with BRUHeaderBar+ScrollView+LazyVStack on the Routines tab list surface (RoutinesListView, RoutineRow, NewFolderSheet, MoveRoutineSheet).

## What Was Built

### Task 1: RoutinesListView + RoutineRow

**RoutinesListView** rewritten from `navigationTitle("Routines")` + `List` + `.toolbar` chrome to:
- `BRUHeaderBar(left: nil, center: "Routines", right: HeaderAction("+ NEW", isSignal: true))` via `.safeAreaInset(edge: .top)`
- `ScrollView > LazyVStack(spacing: 0, pinnedViews: [.sectionHeaders])` with `Section { ... } header: { BRUSectionHead }` per folder group
- `BRUDivider(.hair)` between rows replacing `List` separator
- `confirmationDialog` for "+ NEW" menu (Routine / Folder options)
- Empty state: `BRUDisplay("No routines yet", size: .large)` + `BRUButton("+ NEW ROUTINE", .signal)`
- Blocks section restyled with `BRUFont`/`BRUSectionHead` (preserving `BlockRow` + block CRUD)

All Phase 2 behaviors preserved verbatim: soft-ref folder delete (re-map routine.folderID = nil before ctx.delete(folder)), active-session-conflict alert ("Workout in Progress"), SupersetGroup orphan cleanup, NavigationPath routing to SessionLoggerView.

**RoutineRow** rewritten to 3-column BRU layout per UI-SPEC line 310+547:
- Leading 64pt: `BRUFont.displayMedium` day-count/muscle-hint or "—" fallback
- Middle: `BRUFont.bodyEmphasis` routine name + `BRUFont.labelSmall` "{N} exercises" sub-line
- Trailing: "▸" chevron text glyph in `bruMuted` (Phase 6 tonnage helper not yet available)
- Swipe actions and context menu preserved verbatim; `.tint(Color.accentColor)` removed

### Task 2: NewFolderSheet + MoveRoutineSheet

**NewFolderSheet** rewritten:
- `BRUHeaderBar(left: HeaderAction("CANCEL"), center: "NEW FOLDER", right: HeaderAction("SAVE", isSignal: true))`
- `BRUFont.bodyDefault` TextField with "Folder name" placeholder + 2pt `bruInk` underline
- `FOLDER NAME` label in `BRUFont.labelSmall` tracking 1.2 uppercase

**MoveRoutineSheet** rewritten:
- `BRUHeaderBar(left: HeaderAction("CANCEL"), center: "MOVE ROUTINE", right: nil)`
- `"✓"` text glyph (NOT `Image(systemName: "checkmark")`) for selected-folder indicator
- Immediate write-and-dismiss on row tap (no separate Save action)

Both files: zero `Color.accentColor`, zero `Image(systemName:)`, zero Apple font styles.

## Folder-Grouping Policy

Sort order: "UNFILED" section first (only when ≥1 routine has `folderID == nil`), then user folders in ascending `sortOrder` order (driven by `@Query(sort: \RoutineFolder.sortOrder)`). "UNFILED" section head text is hardcoded uppercase per UI-SPEC line 308. Empty folder sections are suppressed (same as Phase 2 convention — a folder only renders when it has at least one matching routine AND the search filter passes).

## Last-Session Tonnage Source

`lastSessionTonnage` returns `nil` in this phase — the Phase 6 `.fitbodbackup` / session-history helpers that aggregate per-routine tonnage are not yet wired into the Routines tab. The "▸" text glyph fallback is shown per UI-SPEC line 310. This stub is intentional; Phase 6 polish will wire the tonnage query.
