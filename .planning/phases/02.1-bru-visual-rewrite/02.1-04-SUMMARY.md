# Phase 02.1 Plan 04: TodayView BRU Rewrite Summary

Standalone BRU Today tab — extracted 219-line inline `private struct TodayView` from RootView.swift and composed the full BRU layout with 7 sub-components, preserving all Phase 4 + Phase 5 behaviors verbatim.

## Final Composition Order

Per UI-SPEC line 533 (shipped order):

```
safeAreaInset(edge: .top):
  BRUHeaderBar(left: nil, center: "Fitbod / Today", right: HeaderAction(formattedDate))

ScrollView > VStack(spacing: 0):
  1. DeloadWeekBanner       [Phase 5 — defensive-top, phase.kind == .deload]
  2. DeloadAdvisoryBanner   [Phase 5 — currentAdvisory != nil]
  3. TodayStatStrip         [Day streak / Sessions / W{N}/{M} ↑↓—]
  4. BlockContextBand       [Block chip + name + phase chip + WeekTickerCells]
  5a. ResumeWorkoutSlab     [completedAt == nil → active session branch]
  5b. BlackSlabCTA          [todaysRoutine exists → scheduled workout branch]
  5c. StartBlockCTA         [activeBlocks.isEmpty → no block branch]
  5d. empty-state           [block active, no routine scheduled]
  6. LiftListSection        [BRUSectionHead("Lift list") + LazyVStack of LiftListRow]
  7. FatigueSurfaceView     [Phase 5 — defensive-bottom]
```
