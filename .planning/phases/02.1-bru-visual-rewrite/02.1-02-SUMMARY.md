## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] BRUCornerBadge.swift Swift 6 internal Color default-arg error**
- **Found during:** Task 1 (first build attempt)
- **Issue:** `BRUCornerBadge.init` used `fill: Color = .bruSignal` and `textColor: Color = .bruPaper` as `public` default args. Under Swift 6 `MemberImportVisibility`, `internal` generated asset symbols cannot appear in `public` default argument positions.
- **Fix:** Applied `Color? = nil` nil-coalescing pattern (parallel plan 02.1-03 later established this as the project-wide convention and added the comment to `Color+BRU.swift`).
- **Files modified:** `fitbod/Design/BRUCornerBadge.swift`
- **Commit:** 05c908c (included in Task 2 commit)

**2. [Rule 1 - Bug] Color.bru* tokens not accessible from FitbodWidgetsExtension**
- **Found during:** Task 3 (first widget build attempt after adding primitives to membershipExceptions)
- **Issue:** Generated `Color.bru*` extensions from `ASSETCATALOG_COMPILER_GENERATE_SWIFT_ASSET_SYMBOL_EXTENSIONS` live only in the main app's DerivedSources. Files shared to the widget target via `membershipExceptions` couldn't see them.
- **Fix:** Plan 02.1-03 (parallel sibling, committed 50e3978) resolved this by: (a) adding `public static let Color` extensions using `Color("name")` to `Color+BRU.swift`, and (b) setting `ASSETCATALOG_COMPILER_GENERATE_SWIFT_ASSET_SYMBOL_EXTENSIONS = NO` at the `fitbod` target level to prevent redeclaration conflicts.
- **Files modified:** `fitbod/Design/Color+BRU.swift`, `fitbod.xcodeproj/project.pbxproj`
- **Commit:** 50e3978 (committed by Plan 02.1-03 before our Task 3 ran; we inherited the fix)

**3. [Rule 1 - Bug] BRUChip and BRUDisplay init color defaults — nil-Optional pattern**
- **Found during:** Task 1 (build failure)
- **Issue:** Same Swift 6 `MemberImportVisibility` issue as BRUCornerBadge.
- **Fix:** Applied `Color? = nil` nil-coalescing pattern per project convention. Both primitives' Color defaults resolve to `Color.bruInk` inside the init body.
- **Files modified:** `fitbod/Design/BRUChip.swift`, `fitbod/Design/BRUDisplay.swift`
