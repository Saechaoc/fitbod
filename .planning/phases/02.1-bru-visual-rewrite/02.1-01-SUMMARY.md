## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] SpaceGrotesk font files were corrupt HTML from bad GitHub download**
- Found during: Task verification (font tests failing)
- Issue: Prior executor's `curl` against GitHub blob URLs returned HTML page content (not raw bytes); `SpaceGrotesk-Bold.otf` and `SpaceGrotesk-SemiBold.otf` were HTML documents
- Fix: Downloaded valid TTF files from Google Fonts gstatic CDN; confirmed PostScript names "SpaceGrotesk-Bold" and "SpaceGrotesk-SemiBold" via `fc-query`/CoreText verification
- Files modified: Replaced corrupt OTF files with valid TTF files; updated all filename references from `.otf` to `.ttf`
- Commit: 8c470cb

**2. [Rule 1 - Bug] Color+BRU.swift could not define Color.bru* extensions — auto-generated conflict**
- Found during: Task 3 compilation
- Issue: `ASSETCATALOG_COMPILER_GENERATE_SWIFT_ASSET_SYMBOL_EXTENSIONS = YES` already generates `extension SwiftUI.Color { static var bruInk: Color }` etc. in `DerivedSources/GeneratedAssetSymbols.swift`; manual redeclarations caused "invalid redeclaration" build errors
- Fix: Color+BRU.swift made documentation-only (no code); the auto-generated extensions ARE the implementation and are immediately available project-wide
- Commit: 8c470cb

**3. [Rule 1 - Bug] pbxproj required Python binary mode for safe edits**
- Found during: Task 4 pbxproj wiring
- Issue: Text-mode edits (Edit tool, Python text mode) introduced encoding artifacts in Xcode's ASCII plist format; `Color+BRU.swift` filename with `+` character is a reserved ASCII plist token requiring quoting
- Fix: All pbxproj edits via `python3` with `rb`/`wb` binary I/O; filename quoted as `"Design/Color+BRU.swift"` in membershipExceptions
- Commit: 8c470cb
