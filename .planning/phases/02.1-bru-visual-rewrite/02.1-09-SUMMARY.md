## RestTimerProgressArc Canvas geometry shipped

- `lineWidth` default: 4pt (collapsed 32pt arc uses 3pt; expanded 200pt arc uses 6pt — passed by caller)
- Sweep direction: clockwise from -90° (12-o'clock), `endAngle = -90 + 360 * progress`
- Track: full 360° circle in `Color.bruFaint`
- Signal arc: `Color.bruSignal` with `.round` lineCap
- reduceMotion formula: `round(rawProgress * 4) / 4` — bins to 0.0/0.25/0.5/0.75/1.0; guard `> 0` prevents empty arc at non-zero remaining

## Dynamic Island layout decisions

- **Compact leading glyph:** 12×12pt `Rectangle().fill(Color.bruInk)` — explicit dimensions per UI-SPEC line 412
- **Compact trailing:** `BRUFont.bodyEmphasis` (JetBrains Mono Bold 14pt) + `.monospacedDigit()` + `Color.bruPaper`
- **Minimal Canvas arc:** 22pt circle, 2pt lineWidth, bruFaint track + bruSignal progress; same addArc formula as main arc
- **Expanded layout:** `.center` region gets `RestTimerDynamicIslandExpandedView`; `.leading`/`.trailing`/`.bottom` are `EmptyView` to avoid double-rendering the progress bar that's already inside the expanded view

## ActivityKit / Swift 6 pattern honored

`@preconcurrency import ActivityKit` is present at the top of `RestTimerLiveActivity.swift`. All `ContentState` access happens inside the `context` closure (passed by ActivityKit's runtime) — no outer-scope capture. No `Task { }` body ContentState construction was needed since this is a `Widget.body` (read-only context), not an `Activity.update()` call site.

## Decisions Made

- Canvas + addArc over Circle.trim: matches UI-SPEC line 525 verbatim, avoids `.rotationEffect` hack
- reduceMotion 25%-bin: `round(progress * 4) / 4` — bins never reach 0 while remaining > 0 (prevents arc vanishing mid-countdown per threat T-02.1-09-04)
- Expanded DI layout uses `.center` region only: all content (exercise name + countdown + progress bar) is self-contained in `RestTimerDynamicIslandExpandedView`, avoiding double-rendering artifacts
- `RestTimerProgressArc` not in pbxproj: main app uses `PBXFileSystemSynchronizedRootGroup`, which auto-includes all `.swift` files in the `fitbod/` folder; xcodebuild confirmed the file compiled without an explicit entry
- `Capsule()` removed from preview in `RestTimerDynamicIslandCompactView.swift` after banned-token scan caught it (the preview chrome shape is a Dynamic Island frame, not BRU UI — but the ban is absolute per plan)
