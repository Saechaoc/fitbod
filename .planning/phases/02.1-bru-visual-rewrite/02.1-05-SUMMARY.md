## What Was Built

**RoutineBuilderView** (487 lines): Full replacement of Form/Section/editMode approach. Structure: `NavigationStack { ZStack(alignment: .bottom) { VStack(spacing: 0) { .safeAreaInset(top: BRUHeaderBar) + nameAndChipBlock + RoutineBuilderDayTabs + exerciseScrollView } + BottomActionBar } }`. BRUHeaderBar carries "‹ Back" / "Edit routine"|"New routine" center / "•••" menu. Chip row: intent BRUChip (signal-fill when .strength) + days/wk + ~52min + block chip. `.confirmationDialog("Discard changes?")` with verbatim copy preserved.

**BottomActionBar** (103 lines): 2pt bruInk top rule + HStack of `BRUButton("Discard", .ghost)` + 2pt bruInk Rectangle separator + `BRUButton("Save routine ▸", .signal)`. isValid gates the save button with opacity(0.4) when false.

**RoutineBuilderDayTabs** (155 lines): Horizontal strip, HStack(spacing: 0) of day buttons with 1pt bruInk Rectangle separators. Active: bruInk fill + bruPaper text. Inactive: clear fill + bruInk text. Trailing "+" tab 36pt wide in bruSignal. 2pt bruInk BRUDivider(.ink) bottom rule. Defines `RoutineDay: Identifiable, Hashable` locally.

**SetRowsContainer** (162 lines): VStack(spacing: 0) of PerSetOverrideRows separated by BRUDivider(.hair). `.overlay(Rectangle().stroke(Color.bruInk, lineWidth: 1.5))` outer border. Shows default set rows when no overrides exist.

**RoutineExerciseCard** (220 lines): Leading: SpaceGrotesk-Bold 26pt zero-padded index ("01"/"02" or "SS" in bruSignal for supersets). Middle: BRUFont.bodyEmphasis name + BRUFont.labelSmall .textCase(.uppercase) bruMuted sub-line. Trailing: `Text("⋮⋮")` typographic glyph (not SF Symbol). `BRUSupersetBracket { cardBody }` wraps when supersetGroupID != nil.

**PrescriptionEditorRow** (467 lines): 5-chip top row (reps / RPE / progression-signal / rest / plate) + SetRowsContainer. Advanced section behind "EDIT PRESCRIPTION" toggle preserving all Phase 3/3.1/4 behavior. TOP row gets bruSignal.opacity(0.06) tint background via isTop parameter on PerSetOverrideRow.

**InlineExerciseSearchRow** (54 lines): `BRUDashedSlot(label: "Add exercise", hint: "↘ FROM LIBRARY", leadingGlyph: "+")` replacing Image(systemName: "plus.circle") + accentColor.

**SupersetAssignmentSheet** (133 lines): `.navigationBarHidden(true)` + `.safeAreaInset { BRUHeaderBar(left: "Cancel", center: "ADD TO SUPERSET") }`. "New Superset" replaced by `BRUButton(.signal, "+ New superset")`. Body rows use bodyEmphasis 14pt + BRUDivider(.hair) separators.

**RoutineBuilderBRUCopyTests** (146 lines): 8 @Test source-anchor functions reading .swift files via #filePath ascent:
1. "Edit routine" in edit mode
2. "New routine" in create mode
3. "Discard" + "Save routine ▸" in BottomActionBar
4. "Add exercise" + "↘ FROM LIBRARY" in InlineExerciseSearchRow/RoutineBuilderView
5. reps/RPE/autoreg/rest/Plate chips + BRUChip + SetRowsContainer in PrescriptionEditorRow
6. "⋮⋮" glyph present, "line.3.horizontal" / "arrow.up.arrow.down" absent in RoutineExerciseCard
7. "Discard changes?" + "Your edits will not be saved." + "Keep editing" in RoutineBuilderView
8. bruSignal + opacity + "TOP" + isTop in PerSetOverrideRow

## Known Stubs

- **RoutineBuilderDayTabs** is a visual shell over a single-day RoutineDraft. The RoutineBuilderView uses a single `UUID` stub (`dayTabID`) so the tab strip shows one day. Multi-day routing will be wired in a future plan without changing this component's API (documented in file header comment, lines 18-22).
- **PrescriptionEditorRow progression chip** shows static "RPE autoreg" text — this is intentional per Phase 3.1 PIVOT-04 (progressionKind hoisted to RoutineDraft level; per-exercise display removed). Not a stub — correctly reflects the current data model.
- **"~52 min"** in the header chip row is a placeholder display value; session duration estimation is out of scope for Phase 2.1 and is documented in the chip label.
