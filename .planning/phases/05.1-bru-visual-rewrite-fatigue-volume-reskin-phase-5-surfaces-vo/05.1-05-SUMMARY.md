## Decisions Made

- **BRUSectionHead `right:` parameter:** Plan pseudocode used `rightSlot:` label; actual `BRUSectionHead` API is `right: String?`. Used correct API.
- **summarySlab + legendStrip always visible:** Both render even in empty state so the chrome is consistent — empty state only replaces the volume + heatmap sections below the legend.
- **`hasVolumeData` guard:** Empty state condition is `visibleMuscles.isEmpty` (same logic as Phase 5 baseline), not a separate data check.
- **`deltaCopy` computed inline:** Sum of `(currentWeekTotal - previousWeekTotal)` across all visible muscles; negative renders as `-N`, zero renders as `±0`, positive as `+N` per volume.jsx line 32.
