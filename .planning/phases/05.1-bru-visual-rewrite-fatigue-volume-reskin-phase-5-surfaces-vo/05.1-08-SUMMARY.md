**1. [Rule 1 - Bug] BRUSectionHead uses `right:` not `rightSlot:`**

- **Issue:** Plan spec said `rightSlot:` but BRUSectionHead.init signature uses `right:`

- **Files modified:** fitbod/ExerciseLibrary/ExerciseDetailView.swift

**2. [Rule 1 - Bug] BRUFont usage pattern is `.font(BRUFont.bodyDefault)` not `.font(.bruFont(...))`**
- **Found during:** Task 1 — build error `type 'Font?' has no member 'bruFont'`
- **Issue:** Plan spec used `.font(.bruFont(BRUFont.bodyDefault))` but existing Phase 5 code uses `.font(BRUFont.bodyDefault)` directly
- **Fix:** Matched the pattern from PerMuscleDetailView.swift
- **Files modified:** fitbod/ExerciseLibrary/ExerciseDetailView.swift
- **Commit:** cb98d60 (same task commit)

**3. [Rule 1 - Bug] `Color.bruMuted` requires explicit `Color.` prefix**
- **Found during:** Task 1 — build error `type 'ShapeStyle' has no member 'bruMuted'`
- **Issue:** Plan spec used `.foregroundStyle(.bruMuted)` but the extension is `Color.bruMuted` not a ShapeStyle shorthand
- **Fix:** Changed to `Color.bruMuted`
- **Files modified:** fitbod/ExerciseLibrary/ExerciseDetailView.swift
- **Commit:** cb98d60 (same task commit)

**4. [Rule 1 - Bug] VolumeZone regex unescaped parens/quotes**
- **Found during:** Task 2 — all 3 @Test functions failed with `NSCocoaErrorDomain Code=2048 "The value 'Color("Volume...')' is invalid"`
- **Issue:** `#"Color\("Volume[A-Za-z]+")"#` has unescaped `(`, `)`, and `"` inside the raw string — NSRegularExpression rejected as invalid regex
- **Fix:** Changed to `#"Color\(\"Volume[A-Za-z]+\"\)"#` (escaped the inner parens and quotes)
- **Files modified:** fitbodTests/BRUPhase5GrepAuditTests.swift
- **Commit:** 9b6a947 (same task commit after fix)
