## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] SRCROOT env var not available at test runtime**
- **Found during:** Task 1 test RED phase (all 4 tests failed: `sourceText` returned empty string)
- **Issue:** Tests used `ProcessInfo.processInfo.environment["SRCROOT"]` to find source files; `SRCROOT` is not set in the test runner environment
- **Fix:** Switched to `#filePath` compile-time constant to derive project root (identical to `BRUGrepAuditTests` precedent in the codebase)
- **Files modified:** `fitbodTests/PerMuscleDetailViewBRUTests.swift`, `fitbodTests/MuscleVolumeTargetEditorBRUTests.swift`
- **Commit:** 6c7d4d2 (included in Task 2 commit)

**2. [Rule 2 - Missing functionality] .toolbar(.hidden) needed for NavigationStack push**
- **Found during:** Task 1 implementation analysis
- **Issue:** Both views are pushed via `NavigationLink` in a parent `NavigationStack`. Without suppressing the system nav bar, the BRU header bar and system nav bar would double-render, violating the BRU contract ("Do NOT nest BRUHeaderBar inside a NavigationStack that also has .navigationBarHidden(false)")
- **Fix:** Added `.toolbar(.hidden, for: .navigationBar)` to both views
- **Impact:** Required updating `MuscleVolumeTargetEditorUITests.testNavigateToEditorAndExpandChest` (system nav bar no longer exists to assert against)
- **Files modified:** Both view files + `MuscleVolumeTargetEditorUITests.swift`
