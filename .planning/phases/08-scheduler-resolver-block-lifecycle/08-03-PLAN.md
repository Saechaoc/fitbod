## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| lifecycle mutation → persisted store | Multi-object block mutations must commit atomically; a partial flush corrupts the single-active invariant or leaves a completed block unreadable |
| split delete/archive UI (Phase 9) → service guard | Untrusted delete/archive requests cross into the conditional-deny seam |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
