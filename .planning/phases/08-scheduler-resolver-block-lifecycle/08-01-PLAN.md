    `private static func resolveRotation(block: Block, context: ModelContext) -> TodayResolution`: compute `let slotCount = block.split?.slots?.count ?? 0`; `guard slotCount >= 1 else { return .emptySplit }` (Pitfall 3 — guard BEFORE any modulo). Capture `let targetBlockID = block.id` and `let targetSplitID = block.split?.id` as local lets BEFORE the fetch (Pitfall 1). Fetch with a BROAD `#Predicate { $0.completedAt != nil }` sorted `SortDescriptor(\Session.startedAt, order: .reverse)` — the multi-level chains stay OUT of the predicate. Post-filter in Swift with `.first { session in session.block?.id == targetBlockID && session.slot != nil && session.slot?.split?.id == targetSplitID }` — this single predicate makes ad-hoc / deleted-slot / swapped-split / in-progress sessions all fall out identically (do NOT enumerate cases). Sort slots: `let slots = (block.split?.slots ?? []).sorted { $0.position < $1.position }`. Compute `nextPosition = seed?.slot.map { ($0.position + 1) % slotCount } ?? 0`. Return `slots.first(where: { $0.position == nextPosition }).map(TodayResolution.session) ?? .emptySplit`.

    `private static func resolveFixedWeekly(block: Block, today: Date, calendar: Calendar) -> TodayResolution`: `let slotCount = block.split?.slots?.count ?? 0`; `guard slotCount >= 1 else { return .emptySplit }`. Compute `position = storedIndex % slotCount` (mod is the runtime guard for mid-block slot-count drift per spec §5). Sort slots by position and return `slots.first(where: { $0.position == position }).map(TodayResolution.session) ?? .emptySplit`.
