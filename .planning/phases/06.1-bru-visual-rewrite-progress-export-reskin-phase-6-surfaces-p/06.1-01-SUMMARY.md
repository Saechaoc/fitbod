# Phase 6.1 Plan 01: ProgressHomeView BRU Reskin Summary

BRU-skinned Progress tab root: List/Form replaced by BRUHeaderBar + ScrollView + BRUSectionHead sections with BRUDivider rows and typographic chevron navigation rows.

## What Was Built

`fitbod/Progress/ProgressHomeView.swift` fully migrated from Apple HIG inset-grouped list styling to the BRU brutalist design system:

- `BRUHeaderBar(center: "Progress")` replaces `.navigationTitle("Progress")`
- `ZStack(Color.bruPaper.ignoresSafeArea()) + VStack(spacing: 0) + ScrollView + LazyVStack(spacing: 0)` replaces `List(.insetGrouped)`
- Three sections (Recent / Trends / Compare) each open with `BRUSectionHead(title)` and close with `BRUDivider(.ink)`; consecutive rows separated by `BRUDivider(.hair)`
- Per-exercise Recent rows: `Button { path.append(...) } label: { HStack — VStack(name+sub) — Spacer — "›" }` with `bodyEmphasis bruInk` name, `labelSmall bruMuted` sub-line, `.buttonStyle(.plain)`
- Trends rows (Weekly Tonnage / Personal Records) and Compare row follow identical BRU two-line button pattern
- Empty states use `bruEmptyState(heading:body:)` helper: `bodyEmphasis + bodyDefault` in `bruMuted`, centered, 32pt vertical padding — verbatim UI-SPEC copy ("No history yet" / "Log a session to start seeing your progress.")
- All `@Query` declarations, `ExerciseProgressRoute` + `ProgressHomeRoute` enums, and `.navigationDestination` wiring preserved unchanged
