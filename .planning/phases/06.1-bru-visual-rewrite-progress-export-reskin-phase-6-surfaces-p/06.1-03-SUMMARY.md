# Phase 06.1 Plan 03: ExercisePRsView + SessionComparisonView BRU Reskin Summary

BRU-reskin of ExercisePRsView and SessionComparisonView — replaces Apple HIG Picker(.segmented)/List(.insetGrouped)/Color.accentColor with BRUHeaderBar + 3-segment inverted-active toggle + BRU section/row/divider primitives and BRU delta color contract.

## What Was Built

**ExercisePRsView** (fitbod/Progress/ExercisePRsView.swift):
- BRUHeaderBar(left: ‹ back, center: "Personal Records", right: "ALL TIME")
- 3-segment inverted-active intent toggle bar (Strength / Hypertrophy / All): BRUInk fill + BRUPaper text when selected; UISelectionFeedbackGenerator haptic on tap
- ScrollView + LazyVStack of 4 BRUSectionHead sections (Weight / Reps / Volume / e1RM)
- Rep-bucket sub-headers ("1–6 REPS" / "7–10 REPS" / "11+ REPS") as BRUFont.labelSmall .bruMuted inline dividers
- PR rows: 3-column HStack — 110pt fixed kind label (bruSignal on current-day, bruInk otherwise) + BRUDisplay(.medium) value center + mono date trailing
- Current-day rows: Color.bruSignal.opacity(0.06) row background tint
- e1RM 11+ suppression note "Suppressed for reps above 10." preserved verbatim
- Empty state: BRUFont.bodyEmphasis "No PRs yet" + BRUFont.bodyDefault .bruMuted body; 32pt vertical padding
- placeholderPRsDestination() stub updated to BRUHeaderBar (no .navigationTitle)

**SessionComparisonView** (fitbod/Progress/SessionComparisonView.swift):
- BRUHeaderBar(left: ‹ back, center: "This week vs last week", right: nil)
- Column header row: BRUFont.labelMicro tracking 1.2 .bruMuted uppercase (this-week date | Δ | last-week date)
- BRUDivider(.ink) below header row
- Per-exercise 3-column rows: trailing exercise name + this-week value | center BRUDisplay(.medium) delta | leading last-week value
- Delta color contract: positive → Color.bruSignal, negative → Color.bruMuted, zero/nil → Color.bruFaint
- U+2212 minus sign (NOT hyphen) preserved for negative deltas; U+2014 em-dash for zero
- "No prior data" inline row: BRUFont.bodyDefault .bruMuted single-cell
- Empty state: BRUFont.bodyEmphasis "No comparable session" + BRUFont.bodyDefault .bruMuted body
