## acknowledge() / acknowledgeAndDismiss() Refactor

The original `acknowledgeAndDismiss()` (lines 149–160 of old implementation) called `BlockReviewStatistics.acknowledge(block:context:now:)` then `dismiss()`. This pattern would cause the sheet presented by `pendingNextBlockBuilder` to fail — dismiss() fires before the `.sheet(item:)` can render.

Split:
- `acknowledge()` — calls `BlockReviewStatistics.acknowledge`, sets `acknowledgeError` on failure. NO dismiss.
- `acknowledgeAndDismiss()` — calls `acknowledge()` + `dismiss()`. Preserved for any future callers.

"Start next ▸" calls `acknowledge()` then sets `pendingNextBlockBuilder`. The sheet opens atop the current view. "Plan custom" calls `dismiss()` only (user is deferring — no acknowledge).
