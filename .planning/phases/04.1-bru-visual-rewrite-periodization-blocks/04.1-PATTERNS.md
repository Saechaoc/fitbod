**Mapped:** 2026-05-23
**Files analyzed:** 13 (12 existing + 1 net-new)
**Analogs found:** 13 / 13 (all 12 existing files are their own "before"; the net-new file maps to `BlockReviewView.swift`)

## Phase Nature

This is a **re-skin / refactor**, not a greenfield feature. For each of the 12 existing files, the file IS its own closest analog — the executor reads the current implementation, strips the Apple-HIG layer, and rewrites the body using BRU primitives shipped by Phase 2.1. For the 1 net-new file (`BlockOverviewScreen.swift`), the closest in-repo analog is `BlockReviewView.swift` (similar block-bound full-screen composition with ink hero band + scrollable body + bottom action bar).

The **BRU primitive call-site shape** comes from Phase 2.1's `02.1-01-PLAN.md` foundation. This phase's plans MUST consume those primitives — they MUST NOT redefine `Color.bruInk`, `BRUFont.displayHero`, or any `BRU*` component.

## Shared Patterns (cross-cutting)

### Shared Pattern A — BRU primitive call-site shape

**Source:** Phase 2.1's `02.1-01-PLAN.md` interfaces block + 02-UI-SPEC.md §Component Inventory

**Apply to:** All 13 files (every Phase 04.1 plan).

**Color access** — asset-catalog-backed extension, NOT inline `Color(red:green:blue:)`:

```swift
// CORRECT (Phase 2.1 foundation ships this)
.foregroundStyle(Color.bruSignal)
.background(Color.bruPaper)
Rectangle().fill(Color.bruInk).frame(height: 2)

// WRONG — do not redeclare or use string lookup directly
Color("bruInk")           // verbose; the static let is preferred
Color(red: 1.0, green: 0.36, blue: 0.1)  // bypasses dark-mode asset
```

**Font access** — explicit role enum, never Dynamic Type:

```swift
// CORRECT
Text("BLOCK NAME")
    .font(BRUFont.labelSmall)
    .textCase(.uppercase)
    .tracking(1.2)

Text("Upper hypertrophy")
    .font(BRUFont.displayLarge)

// WRONG
Text("BLOCK NAME").font(.caption)           // semantic style forbidden
Text("BLOCK NAME").font(.custom("SpaceGrotesk-Bold", size: 9))  // bypasses BRUFont
```

**Letterspacing + case** — applied at call site (NOT inside BRUFont; see 02.1-01-PLAN.md interfaces):

```swift
Text("TIMELINE")
    .font(BRUFont.labelSmall)
    .textCase(.uppercase)
    .tracking(1.5)        // per 04-UI-SPEC line 90
    .foregroundStyle(Color.bruInk)
```

**Spacing scale** — values restricted to `{4, 8, 12, 16, 24, 32, 48, 64}`:

```swift
VStack(spacing: 12) { ... }                  // md
.padding(.horizontal, 16).padding(.vertical, 12)  // lg/md per JSX "padding: '12px 16px'"
.frame(height: 56)                           // timeline visual constant (exempt)
.frame(width: 6, height: 6)                  // active indicator dot (component constant)
```

### Shared Pattern B — Border / Rule constants

**Source:** 02-UI-SPEC.md line 82 (locked from Phase 2)

**Apply to:** Every file that draws a divider, section break, or container outline.

```swift
// 2pt section-level ink rule (between header band and body, between body and bottom bar)
Rectangle()
    .fill(Color.bruInk)
    .frame(height: 2)

// 1pt hair divider between consecutive list rows
Rectangle()
    .fill(Color.bruHair)
    .frame(height: 1)

// 1pt cell border (phase-data grid in BlockPhaseEditorRow)
.overlay(Rectangle().stroke(Color.bruInk, lineWidth: 1))

// 2pt outer container border (e.g., 56pt TIMELINE rectangle)
.overlay(Rectangle().stroke(Color.bruInk, lineWidth: 2))
```

**Never** use `Divider()` (sub-pixel hairline) — always `Rectangle().fill(.bruHair).frame(height: 1)` or `BRUDivider(.hair)` if the Phase 2.1 primitive is available.

### Shared Pattern C — BRUChip (replaces every Capsule / Circle visual)

**Source:** 02-UI-SPEC.md line 510 + block-builder.jsx lines 13-18

**Apply to:** Every "chip" or "badge" rendering — `BlockBuilderView` header chip row, `BlockPhaseEditorRow` kind chip, `BlockCard` block + phase chips, `BlockRow` week badge, `MesocycleWeekPage` phase chip + week badge, `BlockPickerMenu` block link chip.

```swift
// Outlined chip (default)
BRUChip("5 WEEKS")                                    // labelSmall ink-outlined rectangle
BRUChip("LINEAR")
BRUChip("DELOAD", color: .bruSignal)                  // signal outline (deload reminder)

// Filled chip (active/now states)
BRUChip("ACTIVE", color: .bruSignal, fill: true)      // signal fill + paper text
BRUChip("NOW",    color: .bruSignal, fill: true)
```

**Implementation contract from 02-UI-SPEC.md line 510:**
- `init(_ label: String, color: Color = .bruInk, fill: Bool = false, textCase: Text.Case? = .uppercase)`
- 1.5pt outline (or fill when `fill: true`)
- Rectangular (NOT Capsule)
- 4–6pt internal padding
- `labelSmall` text

```swift
Canvas { ctx, size in
    // Compute proportional widths from draft.phases.weeks
    let totalWeeks = draft.phases.reduce(0) { $0 + $1.weeks }
    var x: CGFloat = 0
    for phase in draft.phases {
        let width = (CGFloat(phase.weeks) / CGFloat(totalWeeks)) * size.width
        let rect = CGRect(x: x, y: 0, width: width, height: size.height)
        switch phase.kind {
        case .accumulation:
            ctx.fill(Path(rect), with: .color(.bruInk.opacity(0.85)))
        case .intensification:
            ctx.fill(Path(rect), with: .color(.bruSignal))
        case .realization:
            ctx.fill(Path(rect), with: .color(.bruInk.opacity(0.25)))
        case .deload:
            // Diagonal stripe pattern — per 04-UI-SPEC line 437-453
            drawDeloadStripes(ctx: ctx, rect: rect)
        }
        x += width
    }
}
.frame(height: 56)
.overlay(Rectangle().stroke(Color.bruInk, lineWidth: 2))
```

// Implementation per 04-UI-SPEC lines 437-453.
public static func drawDeloadStripes(ctx: GraphicsContext, rect: CGRect) {
    let stripeWidth: CGFloat = 12
    var x = rect.minX - rect.height
    while x < rect.maxX + rect.height {
        let path = Path { p in
            p.move(to: CGPoint(x: x, y: rect.minY))
            p.addLine(to: CGPoint(x: x + 6, y: rect.minY))
            p.addLine(to: CGPoint(x: x + 6 + rect.height, y: rect.maxY))
            p.addLine(to: CGPoint(x: x + rect.height, y: rect.maxY))
            p.closeSubpath()
        }
        ctx.fill(path, with: .color(Color.bruInk.opacity(0.18)))
        x += stripeWidth
    }
}
