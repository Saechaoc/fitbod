## ConsiderDeloadBanner D-16 + D-17 Diff

**D-16 — Removed "Adjust block" Button (CONTEXT D-16: out-of-spec; spec defines only header + body + dismiss):**

```swift
// REMOVED:
Button("Adjust block") {
    // Phase 5 wires the real advisory action.
}
.foregroundStyle(Color.accentColor)
```

**D-17 — Replaced xmark Image dismiss with BRUChip("DISMISS") (CONTEXT D-17):**

```swift
// REMOVED:
Button {
    dismissed = true
} label: {
    Image(systemName: "xmark")
        .foregroundStyle(.secondary)
}
.frame(minWidth: 44, minHeight: 44)
.accessibilityLabel("Dismiss deload advisory")

// REPLACEMENT:
BRUChip("DISMISS")
    .frame(minWidth: 44, minHeight: 44)
    .onTapGesture { dismissed = true }
    .accessibilityLabel("Dismiss deload advisory")
```

The 44pt hit-area frame is applied directly to BRUChip to preserve the HIG minimum touch target.
