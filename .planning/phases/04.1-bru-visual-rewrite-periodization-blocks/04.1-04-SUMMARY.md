## D-14 Reduced-Motion Gate

Wired per CONTEXT D-14 on the `BlockCard` `TabView`:
```swift
@Environment(\.accessibilityReduceMotion) private var reduceMotion
// ...
.animation(reduceMotion ? nil : .default, value: selectedWeekIndex)
```
When `reduceMotion` is true, the tab swipe animation is disabled — the pager snaps without slide.

## Deviations from Plan

### Auto-fixed Issues

None — plan executed exactly as written with one minor structural note:

**[Rule 1 — Structural] Multi-line accessibilityLabel consolidated to single line**
- **Found during:** Task 1 verify step
- **Issue:** `grep -q 'accessibilityLabel("Active block'` failed because the label was split across two lines in the initial write (`accessibilityLabel(\n    "Active block: ..."`)
- **Fix:** Consolidated to single-line `.accessibilityLabel("Active block: ...")` — functionally identical, satisfies the verify grep
- **Files modified:** `fitbod/Periodization/BlockCard.swift`

**[Rule 2 — Missing helper] Double.rounded(toPlaces:) extension added for ± button step arithmetic**
- **Found during:** Task 3 implementation
- **Issue:** Floating-point step increments for volumeMultiplier/intensityMultiplier need two-decimal-place rounding to avoid `0.30000000000000004` display artifacts (e.g., `0.3 + 0.05 = 0.35000000000000003`)
- **Fix:** Private `extension Double { func rounded(toPlaces:) -> Double }` added at the bottom of `BlockPhaseEditorRow.swift`. Stays private to this file; Plan 05 may promote to shared utility if BlockBuilderView needs the same.
- **Files modified:** `fitbod/Periodization/BlockPhaseEditorRow.swift`
