When 02.1-02..02.1-03 eventually run, they MUST find these files already in place and either consume them as-is or reconcile (the primitive shape is locked by 02-UI-SPEC.md — both phases must converge on the same contract).

**Wave 0 precondition guard (revision iter 1 updated per B1; iter 2 updated per B7):** before any other 04.1 plan runs, Plan 01 asserts that the BRU foundation is present via 6 checks: (1) `fitbod/Design/Color+BRU.swift` exists (the file is doc-only — the 8 Color.bru* extensions are auto-generated by Xcode from the .colorset assets), (2) `fitbod/Design/BRUFont.swift` exists with all 7 static let font roles, (3) the 8 CONTEXT D-01 `bru*.colorset` entries (bruInk, bruPaper, bruSignal, bruFaint, bruHair, bruMuted, bruBg, bruBg2) each exist in Assets.xcassets via per-name `test -d` enumeration — this tolerates foundation extras like bruAmber.colorset / bruGreen.colorset shipped by 02.1 and names the missing token in the halt message (revision iter 2 B7 — replaces the iter 1 bulk `-eq 8` count which false-negatived against the actual 10-colorset on-disk reality), (4) ≥4 font files exist under `fitbod/Resources/Fonts/` (extension-agnostic glob), (5) Info.plist has UIAppFonts registered, (6) the downstream xcodebuild build is the load-bearing runtime proof. If the foundation is missing, Plan 01 halts with `BRU foundation missing — run 02.1-01-PLAN.md first` per CONTEXT D-03 (with the colorset check additionally naming the missing token, e.g. `BRU foundation missing (bruInk.colorset absent) — run 02.1-01-PLAN.md first`).

## Snapshot Test Framework (CONTEXT D-23)

Plan 08 ships the visual regression suite. Strategy: **XCTest body-structure assertions under `fitbodTests/`** (NOT image-diff snapshots — no project precedent for image diffs; `ImageRenderer` + `XCTAttachment` would require XCTest anyway). Each rewritten surface gets a test that:
1. Instantiates the view with a deterministic fixture (via `InMemoryContainer` helper already shipped by Phase 6).
2. Renders it inside an `ImageRenderer` to a `UIImage` and attaches the PNG via `XCTAttachment` for manual eyeballing.
3. Asserts the view body source contains the BRU primitive identifiers (`BRUChip`, `BRUHeaderBar`, `Color.bruInk`, `BRUFont.displayHero`, etc.) via `#filePath`-style file-text checks — matches the precedent set by Phase 6's `*CopyTests.swift` suites.

The grep-based audit re-run in Plan 08 is the load-bearing assertion. The image render is for human eyeball QA only. This keeps the test target compatible with CLAUDE.md "UI tests stay on XCTest; new unit-style tests use Swift Testing" — body-structure file-text checks are unit-style tests.
