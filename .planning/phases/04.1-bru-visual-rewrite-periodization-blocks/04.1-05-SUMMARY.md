## Canvas TIMELINE — 4-case switch

```swift
Canvas { ctx, size in
    let total = CGFloat(draft.phases.reduce(0) { $0 + $1.weeks })
    var x: CGFloat = 0
    for phase in draft.phases {
        let width = (CGFloat(phase.weeks) / total) * size.width
        let rect = CGRect(x: x, y: 0, width: width, height: size.height)
        switch phase.kind {
        case .accumulation:  ctx.fill(Path(rect), with: .color(Color.bruInk.opacity(0.85)))
        case .intensification: ctx.fill(Path(rect), with: .color(Color.bruSignal))
        case .realization:   ctx.fill(Path(rect), with: .color(Color.bruInk.opacity(0.25)))
        case .deload:        BlockPhaseColors.drawDeloadStripes(ctx: ctx, rect: rect)
        }
        x += width
    }
}
.frame(height: 56)
.overlay(Rectangle().stroke(Color.bruInk, lineWidth: 2))
```

## Deviations from Plan

### Auto-applied decisions (within task scope)

**1. [Rule 2 - Design decision] BRUSectionHead Menu overlay instead of rightAction wiring**
- **Found during:** Task 1 implementation
- **Issue:** `BRUSectionHead` accepts a `rightAction: (() -> Void)?` that renders a plain `Button`. Passing `rightAction:` would fire a single closure with no sub-menu. The plan required a `Menu` with 4 `BlockPhaseKind` options.
- **Fix:** Kept `rightAction: nil` so the button text renders as the right label (visual), then added a `.overlay(alignment: .trailing) { Menu { ... } label: { Text("+ ADD PHASE") } }` on top of BRUSectionHead — the Menu captures the tap target without extending the primitive. Visual output is identical; the right-action tap opens the kind picker menu.
- **Files modified:** `fitbod/Periodization/BlockBuilderView.swift`

**2. [Rule 2 - Design decision] BRUHeaderBar.slots(.action) instead of .cancel for CANCEL slot**
- **Found during:** Task 1 implementation
- **Issue:** `.cancel` slot in `BRUHeaderBar` auto-invokes `dismiss()` immediately. The existing cancel flow requires `if hasUnsavedChanges { presentingDiscardConfirm = true } else { dismiss() }` — the `.cancel` slot bypasses this guard.
- **Fix:** Used `.action("CANCEL") { if hasUnsavedChanges { ... } else { dismiss() } }` which renders "CANCEL" in `bruInk` (same visual as `.cancel`) but executes the custom closure.
- **Files modified:** `fitbod/Periodization/BlockBuilderView.swift`
