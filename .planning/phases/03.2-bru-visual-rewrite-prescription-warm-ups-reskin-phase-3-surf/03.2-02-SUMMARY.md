# Phase 03.2 Plan 02: BumpBanner + CalibratingBadge BRU Reskin Summary

Flat bruInk slab for BumpBanner (was green-tinted rounded pill) and flat bruMuted rectangle for CalibratingBadge (was gray capsule with Circle dot).

## What Was Built

**Task 1 — BumpBanner flat slab (TDD GREEN)**

`BumpBanner.swift` fully rewritten to BRU contract:
- `Color(.systemGreen).opacity(0.15)` removed → `Color.bruInk` background
- `RoundedRectangle(cornerRadius: 12)` removed → no clipShape at all
- `Image(systemName: "arrow.up.circle")` removed — BRU has no SF Symbols
- `.font(.headline)` removed → `BRUFont.labelSmall` + `.textCase(.uppercase)` + `.tracking(1.2)`
- Height 44pt → 52pt per 03-UI-SPEC § BumpBannerSlab
- Double outer padding removed (was `.padding(.horizontal, 16).padding(.vertical, 8)` wrapping an already-padded slab)
- `unitLabel: String = "kg"` param added — backward-compatible default, enables "BUMPING TO 225 LB" copy
- Banner text verbatim per 03-UI-SPEC line 215: `"BUMPING TO {weight} {unit} — YOU CLEARED THE TOP OF THE RANGE LAST TIME."`
- Accessibility: `.accessibilityLabel("Weight bump: bumping to {weight} {unit}. Tap to dismiss.")` + `.isButton` trait

**Task 2 — CalibratingBadge flat rectangle (TDD GREEN)**

`CalibratingBadge.swift` fully rewritten to BRU contract:
- `Capsule()` clipShape removed → flat rectangle, no clipShape
- `Circle().fill(Color(.systemGray3))` shape removed → `Text("●")` (U+25CF) in `Color.bruMuted`
- `Color(.systemGray5)` background removed → `Color.bruMuted` fill
- `.font(.caption)` removed → `BRUFont.labelMicro` + `.textCase(.uppercase)` + `.tracking(1.2)`
- `Text("calibrating")` lowercase removed → `Text("CALIBRATING")` uppercase source matching 03-UI-SPEC line 199
- `BRUCornerBadge` NOT composed — it uses SpaceGrotesk-Bold 7pt; spec requires JetBrainsMono-Bold labelMicro 8pt
- Accessibility unchanged: `.accessibilityLabel("Calibrating: {n} of {threshold} sets logged. Weight shown as a range.")` + `.isStaticText`
