# Phase 03.2 Plan 05: WhyThisWeightSheet BRU Brutalist Rewrite Summary

BRU brutalist full rewrite of WhyThisWeightSheet from a generic SwiftUI `List { Section { row(...) } }` (v1) to the ink hero slab architecture from `why-weight.jsx`: ink hero slab → BRUSectionHead → 3 numbered step blocks → conditional CalibratingProgressMeter → ghost/signal BRUButton footer bar.

## What Was Built

`fitbod/Sessions/WhyThisWeightSheet.swift` fully rewritten as a `NavigationStack + ScrollView + VStack(spacing: 0)` composition. Zero `List`, `Section`, `Form`. All banned tokens eliminated.

### Hero Slab (bruInk background)
- Status line: `● RECOMMENDED · {FORMULA}` in `bruSignal labelSmall` — U+25CF character in `Text`, NOT a `Circle` shape
- Trailing set-type: `{SET TYPE}` in `bruPaper` 50% opacity
- Hero weight numeral: 128pt `SpaceGrotesk-Bold` in `bruPaper` (Font.custom per-hero override, BRU-canonical face)
- Unit suffix: `displayLarge bruPaper` 60% opacity
- 2pt `bruPaper` top rule → 2-column REPS | RPE sub-band with `bruSignal` RPE numeral

### Numbered Step Blocks
- Each step: `displayMedium 22pt bruSignal` index + `bodyEmphasis` UPPERCASE label + `bodyDefault` body + optional `bruMuted` sub-copy
- Step 01: Last session line / "No prior data — starting fresh." + reps-in-reserve sub-copy
- Step 02: RPE autoreg computation OR double-progression copy (bump / first-session / held) + calibrating/calibrated sub-copy with Phase 3.1 sessionIntent prefix
- Step 03: `{raw} → {rounded}` with rounded weight in `bruSignal bold` + plate list in `bruMuted`

### CalibratingProgressMeter
Renders between step 02 and step 03 when `explanation.status == .calibrating(n, threshold)`. Uses existing `CalibratingProgressMeter(current:threshold:rangeText:)` from plan 03.2-01.

### Footer Bar
`BRUButton(.ghost)` "Override" (left) + `BRUButton(.signal)` "Use {weight} ▸" (right). 2pt `bruInk` top rule overlay. Both stretch to half-width via `.frame(maxWidth: .infinity)`. 24pt `bruBg` safe-area filler below.

### Phase 3.1 Preservation
`calibratingStatusText(current:threshold:)` and `calibratedStatusText()` helpers relocated verbatim (v1 lines 192–213). `incrementText()` parser relocated verbatim (v1 lines 222–235). Session-intent prefix logic preserved exactly.
