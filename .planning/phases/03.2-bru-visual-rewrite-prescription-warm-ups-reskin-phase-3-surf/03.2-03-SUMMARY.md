- **BRUSectionHead header** — "Warm-up ramp" left, "Plate {increment} · ×2 sides" right trailing in bruMuted labelSmall
- **4-column HStack per row** matching `gridTemplateColumns: '36px 1fr 1fr auto'`:
  1. 36pt W{N} label in BRUFont.displayMedium (18pt) Color.bruSignal per reserved-for item 23
  2. 1fr VStack — weight numeral at 22pt SpaceGrotesk-Bold bruInk + pct suffix bodyDefault 50% opacity + "×{reps} @ {rpe}" sub-line in bodyDefault bruMuted

  4. auto plate legend in labelMicro bruMuted tracking 0.5 (e.g. "45+25+10")

- **"WORK SETS BEGIN AT" footer row** — labelSmall 1.2 tracking bruInk left; displayMedium 18pt bruInk right; NO border below (boundary before first working SetRow per 03-UI-SPEC line 228)

### Design Decisions (documented)

**1. Weight numeral at 22pt via .custom vs BRUFont.displayMedium (18pt)**
- Found during: Task 1 implementation
- Plan spec: "BRUFont.displayMedium (22pt)" — but BRUFont.displayMedium is defined as 18pt in BRUFont.swift
- Decision: 03-UI-SPEC line 88 and why-weight.jsx line 111 both specify 22pt for the weight numeral specifically. Used `.custom("SpaceGrotesk-Bold", size: 22)` directly — same approach PlateStackViz uses for its 12pt rotated labels
- Files: WarmupRampRows.swift

**2. computePlates() uses hardcoded default inventory**
- Found during: Task 1 implementation
- Issue: SessionExercise @Model has no `plateInventory` property — the parent SessionExerciseCard resolves the plate inventory from a @Query<PlateInventory> that is out of scope for WarmupRampRows
- Decision: Use a hardcoded standard barbell plate set (45/25/10/5/2.5 kg) as fallback. The mini-viz is decorative at 0.3 scale (labels suppressed); exact plate accuracy is a future integration concern when SessionExerciseCard passes the inventory down. The T-03.2-05 mitigation (empty array on solve failure) is still active
- Files: WarmupRampRows.swift computePlates() helper

**3. topWorkingWeight defaults to sessionExercise.prescribedWeight ?? 0**
- Plan specifies `topWorkingWeight: Double` as a required parameter
- Existing SessionExerciseCard call site only passes 3 params (warmupSets, onSkip, sessionExercise)
- Decision: Made topWorkingWeight optional with a fallback to prescribedWeight to preserve backward compatibility with the existing call site — the parent SessionExerciseCard (owned by a different plan) will pass the explicit value when it wires the footer
