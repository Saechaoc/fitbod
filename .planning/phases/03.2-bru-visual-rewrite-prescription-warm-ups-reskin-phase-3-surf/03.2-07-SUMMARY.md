# Phase 03.2 Plan 07: PlateCalculatorSheet BRU Brutalist Reskin Summary

BRU brutalist plate calculator sheet — Form/Section architecture replaced with BRUHeaderBar + 96pt displayHero target band + bruBg2-filled PLATE STACK zone (PlateStackViz) + 2-column equipment grid + PlateTallyRow read-only inventory list + ghost/primary BRUButton footer bar.

## What Was Built

Full reskin of `fitbod/Settings/PlateCalculatorSheet.swift` from the v1 Form-based layout to the BRU brutalist composition per `plate-calc.jsx` verbatim.

### Architecture (top to bottom, VStack(spacing:0))

1. **BRUHeaderBar** — "‹" dismiss / "Plate calculator" center / "•••" right placeholder
2. **targetBand** — "TARGET" labelSmall + "BAR X + PLATES Y" right label; 96pt `Font.custom("SpaceGrotesk-Bold")` hero weight + unit suffix in `displayLarge bruMuted`; 4 `BRUChip` quick-adjust chips (`−5 / −2.5 / +2.5 / +5`, ink-outline per spec item 25); 2pt bruInk bottom rule
3. **barExceedsTargetError** — conditional bruSignal `labelSmall` inline caption (replaces v1 `Color(.systemRed)` Section footer)
4. **plateStackZone** — bruBg2 fill + 2pt bruInk overlay rules top and bottom + "PER SIDE" labelSmall + `PlateStackViz(heightScale:1.0, showLegend:true)` when solved; bruSignal "NO COMBINATION FOUND. ADJUST INVENTORY." when no solution (replaces v1 duplicate copy at lines 96+104)
5. **equipmentGrid** — `BRUSectionHead("Equipment", right:"Tap to change")` + 2-column HStack with 1pt bruHair vertical separator + 2pt bruInk bottom overlay rule; barName / inventoryName labels in `displayMedium` 20pt
6. **platesAvailableList** — `BRUSectionHead("Plates available", right:"Per side")` + `LazyVStack` of `PlateTallyRow(weight:count:.constant(plate.countPerSide):unitLabel:)` — read-only per T-03.2-14 / PlateInventoryEditor-is-the-editor contract
7. **footerBar** — 2pt bruInk top rule + `BRUButton(.ghost)` "Save inventory" + `BRUButton(.primary)` "Done ▸"
8. **bruBgFiller** — `Rectangle().fill(Color.bruBg).frame(height:24)` safe-area padding

### Implementation Adjustments

**1. [Rule 2 - Input validation] Quick-adjust chip floors at 0**

- **Found during:** Task 1 implementation
- **Issue:** Tapping `−5` on a 0 weight target would produce negative values
- **Fix:** `let newValue = max(0, current + delta)` guards against negative target weight
- **Files modified:** fitbod/Settings/PlateCalculatorSheet.swift

**2. [Scope - Preview] Replaced PreviewModelContainer.make() with inline ModelContainer**

- **Found during:** Task 1 — preview block
- **Issue:** `PreviewModelContainer.make()` is not findable in the production target (defined in Models/Exercise+Preview.swift but not visible from Settings)
- **Fix:** Used `try! ModelContainer(for:PlateInventory.self, configurations:ModelConfiguration(isStoredInMemoryOnly:true))` directly — same pattern as the original v1 preview
- **Files modified:** fitbod/Settings/PlateCalculatorSheet.swift (preview only)
