```
public struct BlockNameField: View {
    public let title: String
    public let placeholder: String
    @Binding public var text: String

    @FocusState private var isFocused: Bool

    public init(title: String, placeholder: String, text: Binding<String>) {
        self.title = title
        self.placeholder = placeholder
        self._text = text
    }

    public var body: some View {
        VStack(alignment: .leading, spacing: 0) {
            Text(title)
                .font(BlockNameFieldType.label)
                .tracking(BlockNameFieldTokens.labelTracking)
                .foregroundStyle(BlockNameFieldTokens.muted)
                .padding(.top, 16)

            ZStack(alignment: .leading) {
                if text.isEmpty {
                    Text(placeholder)
                        .font(BlockNameFieldType.displayLarge)
                        .foregroundStyle(BlockNameFieldTokens.muted)
                        .lineLimit(1)
                        .allowsHitTesting(false)
                }

                TextField("", text: $text)
                    .font(text.isEmpty ? BlockNameFieldType.displayLarge : BlockNameFieldType.display)
                    .textInputAutocapitalization(.words)
                    .foregroundStyle(BlockNameFieldTokens.ink)
                    .tint(BlockNameFieldTokens.ink)
                    .focused($isFocused)
                    .frame(height: 46)
            }
            .padding(.top, 2)
            .contentShape(Rectangle())
            .onTapGesture { isFocused = true }
        }
    }
}
```

Critical behavioral notes the implementation MUST respect (read carefully, do not over-elaborate):

- NO `.opacity(...)` on the TextField. The whole point of this refactor is removing the 0.02 hack. The TextField is always at full opacity; when `text.isEmpty == true`, the TextField simply has no glyphs to draw, so the placeholder Text underneath shows through unobstructed.

- NO manual cursor Rectangle. When `isFocused == true && text.isEmpty == true`, iOS draws the native cursor on the empty TextField, sized by the active font. Because the TextField's font matches `displayLarge` (44pt BebasNeue) when empty, the native cursor will be visually proportional to the placeholder type — close enough to the previous 2x38 manual cursor. We accept whatever native cursor iOS draws as the new affordance.

- `.allowsHitTesting(false)` on the placeholder Text means taps fall through to the TextField below. The outer `.contentShape(Rectangle())` + `.onTapGesture { isFocused = true }` is a belt-and-suspenders guarantee for the area outside the TextField's natural glyph-hit rect (notably the right side of the row before any text exists).

- The TextField font switches conditionally: `text.isEmpty ? displayLarge (44pt) : display (39pt)`. Mirrors the original `nameFont` computed property in `NewBlockNameBand`. When the placeholder is showing (text empty), the TextField is sized to 44pt so the native cursor matches the placeholder's height. When the user types, the field shrinks to 39pt ink display type.

- The component is intentionally NOT a `@MainActor`-isolated declaration. SwiftUI views default to `@MainActor` at the type level via `View` conformance + `body` — no explicit annotation needed. Swift 6 strict-concurrency stays clean because we only touch `@MainActor` SwiftUI surface and a `@FocusState` (which is `@MainActor`-safe by design).

- No `#Preview` block in this file for v1. The component is exercised through `BlockBuilderView`'s existing `#Preview` definitions; adding standalone previews here is out of scope (the user confirmed "just this refactor, no other surface changes"). If the executor adds one, it must be inside an `#if DEBUG` block and must not break Swift 6 compilation — but it's safer to skip.

- No accessibility annotations beyond what SwiftUI synthesizes. The TextField already exposes itself to VoiceOver via its `text` binding; the label Text is read separately. Don't add `.accessibilityElement(children: .combine)` or labels — keep this faithful to the original implementation, which had none.
