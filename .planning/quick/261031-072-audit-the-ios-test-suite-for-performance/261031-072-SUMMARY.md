# Quick task 261031-072: audit the test suite for performance

**The guide at docs/test-performance-guide.md says the unit target is fast, the UI bundle is the cost, and no recorded run reaches 200 minutes.**

## What was measured

- Toolchain: Xcode 26.5 (17F42) on an Apple M4 with 32 GB; CI is GitHub `macos-26` with 3 vCPUs and 7 GB.
- Unit target: 1,118 tests in 188 suites, 22.0 s of execution, 36 s of wall time serially and 51 s under clones.
- Cold `build-for-testing`: 30 to 31 s, compile-bound and parallel; warm: 1 s.
- UI sample of 24 tests from six October suites: 632 s serially (25.6 s per test), 281 s on four clones (2.25 times faster) with one failure in `SettingsExportUITests/testRestoreAsksBeforeReplacingData` that passes serially.
- One UI test's activity tree: 5 s launch with store reset and catalog import, 1.0 to 1.1 s per satisfied `waitForExistence`, 1.1 to 2.8 s per tap, 1.8 to 2.0 s per 1.2 s long press.
- Phase 0 baseline on Oct 28: 1,026 tests in 15.8 min with 55 UI tests; the UI target has 202 tests today.
- CI: 13 runs on Oct 4, mean 30.1 min, max 55.8 min, one sequential job on both phones, no run on `main` since.

## What the guide proposes

Quick wins: delete the template UI tests, add test timeouts and `-collect-test-diagnostics never` to CI, check `exists` before `waitForExistence`, shorten polling steps, keep the unit target serial, run CI on `main`.
Moderate: a reset that keeps the catalog, animations off for test launches, a CI build job plus a matrix, width-sensitive suite lists, a quiet test host, injected `UserDefaults` in the seeders.
Larger: clone-parallel local UI runs, CI shards, moving copy checks into hosted-view unit tests, direct routes for text-size tests, trimming `.serialized` and `@MainActor`.
The first five actions start with a measured baseline on both phones.

## Missing evidence

- No record of a 200-minute run; the guide's section 5.2 produces the number in one run.
- No CI run has executed the October suites.
- The cost of a launch without the reset flag is unmeasured.
- Clone stability is measured on 24 tests only.
