# Milestone 1 — Chalkline design system + working journey

Executed outside the GSD command flow (the GSD skills were not available in
the agent session); this record keeps `.planning` in sync by hand.

## Goal

A reusable design system ("Chalkline") and a working, persisted workout
journey on it: library search/filter/detail/custom → routine builder →
start workout → log sets, rest timer → resume after relaunch → finish →
summary, history, previous performance.

## Tasks

1. Design foundation: semantic color (light/dark/Increase Contrast), type,
   spacing, radii, strokes, touch sizes, icon and state rules;
   accessibility rules. Explore on a Claude Design canvas.
2. Validate on real screens (library, routine builder, active workout) with
   realistic data, long names, and empty / populated / editing /
   validation-error / completed states.
3. Implement natively: tokens + components (`fitbod/DesignSystem`), an
   in-app component gallery, SwiftUI previews, design ↔ code mapping.
4. Rebuild the journey on the system: Today, Library, Routines (list,
   detail, builder), workout cover (set rows, rest dock/sheet, finish,
   discard, resume), summary, History, Settings.
5. Guarantees: local persistence, workouts as snapshots, absolute-deadline
   rest timer persisted across relaunch, every visible action works.
6. Verify natively: CI on a macOS runner (Xcode 26.x) — build, unit
   tests, XCUITest journey with terminate/relaunch, layout audit on the
   smallest and largest iPhone at default/accessibility text sizes.
7. Document: setup, design system, component map, screen specs,
   verification evidence, roadmap.

## Constraints honoured

- No schema changes (versioned schemas reference live classes; see
  docs/roadmap.md P0).
- Local-only, no third-party dependencies.
- CI added only because the agent has no Mac; it is optional for local work.
