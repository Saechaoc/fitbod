# Quick Task 260528-vi2: New Block screen → rounded-card layout

## Objective

The New Block editor (`BlockBuilderView.swift`) currently renders as a hard-bordered
**table**: a `List(.plain)` of full-bleed rows separated by black ink-rules (`NewBlockInkRule`)
and hairline dividers. The target mockup `bru-screens/New-block/final-design.png` is a stack of
**soft rounded white cards floating on a warm paper background**, with generous margins and gaps.

Convert the screen to the mockup's card aesthetic, addressing the user's 8 issues (priority order):

1. Remove the hard bordered table layout (the `List` + `NewBlockInkRule`/hairline chrome).
2. Convert sections back into rounded cards (white surface, soft border + shadow).
3. Match the mockup's spacing and margins (uniform ~20pt side margins, ~14pt gaps between cards).
4. Restore the large block-name hierarchy (big Bebas display, breathing room, trailing pencil icon).
5. Make the stats card a single rounded card (it already is one card — make it read as a *floating white card*, add calendar icon, inset divider).
6. Make the chart visually match the mockup's card style (rounded white card, faint colored phase bands behind the line; drop the hard ink-rectangle border).
7. Use compact rounded phase cards instead of full-width table rows (each phase = its own ~68pt rounded card with badge + name/subtitle + compact stats + chevron).
8. Match the bottom button layout exactly (ghost `CANCEL` on the left + filled black rounded `SAVE TEMPLATE` on the right, inset with margins; no heavy 3pt rule).

This is a **pure view-layer restyle**. No data-model, no schema, no behavior-removal beyond the
explicitly-relocated controls noted below.

## Design tokens (add to `NewBlockScreenTokens`, exact values)

```swift
// Card surface system (rounded-card restyle 260528-vi2)
static let card        = Color(red: 252 / 255, green: 251 / 255, blue: 248 / 255) // #FCFBF8 warm white
static let cardStroke  = Color(red: 225 / 255, green: 222 / 255, blue: 214 / 255) // #E1DED6 faint border
static let cardShadow  = Color.black.opacity(0.06)

static let screenMargin: CGFloat   = 20  // uniform L/R margin for ALL main-scroll content
static let cardGap: CGFloat        = 14  // vertical spacing between stacked cards
static let cardPadding: CGFloat    = 16  // internal card padding
static let cardRadius: CGFloat     = 18  // stats + chart big cards
static let phaseCardRadius: CGFloat = 14 // phase cards
static let cardStrokeWidth: CGFloat = 0.75
```

Reuse existing `paper` (#F0EDE5) as the page background, `ink`, `muted`, `signal`, `hair`, `faint`.
Add a private card modifier to apply fill + radius + faint stroke + soft shadow consistently:

```swift
private extension View {
    func bruCard(radius: CGFloat = NewBlockScreenTokens.cardRadius) -> some View {
        self
            .background(NewBlockScreenTokens.card)
            .clipShape(RoundedRectangle(cornerRadius: radius, style: .continuous))
            .overlay(
                RoundedRectangle(cornerRadius: radius, style: .continuous)
                    .stroke(NewBlockScreenTokens.cardStroke, lineWidth: NewBlockScreenTokens.cardStrokeWidth)
            )
            .shadow(color: NewBlockScreenTokens.cardShadow, radius: 10, x: 0, y: 3)
    }
}
```
