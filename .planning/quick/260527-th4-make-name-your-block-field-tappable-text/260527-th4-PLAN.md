Edit `NewBlockNameBand` (currently lines 270-322) to make the name area behave like a real text input while preserving the BRU placeholder typography.

Changes inside `NewBlockNameBand`:

1. Add a focus-state property at the top of the struct, alongside `@Bindable var draft: BlockDraft`:
   - Declare `@FocusState private var isNameFocused: Bool` as a private property of the struct.

2. On the existing `TextField("", text: $draft.name)`:
   - Attach `.focused($isNameFocused)`.
   - Replace the always-muted `.opacity(draft.name.isEmpty ? 0.02 : 1)` so the text field is no longer effectively invisible. The intent: when the user has typed something, show the user's text normally (opacity 1). When empty, the field can stay at very low opacity (it's behind the placeholder) — keep `0.02` for the empty case so the placeholder text remains the visible affordance, but rely on the new tap gesture (below) for hit-testing rather than the field's own invisible glyph area.
   - Keep everything else on the TextField identical: `.font(nameFont)`, `.textInputAutocapitalization(.words)`, `.foregroundStyle(NewBlockScreenTokens.ink)`, `.tint(NewBlockScreenTokens.ink)`, `.frame(height: 46)`.

3. On the placeholder overlay (the `if draft.name.isEmpty { HStack { ... } }` block):
   - KEEP the `Text("NAME YOUR BLOCK")` with `NewBlockType.displayLarge` + `.foregroundStyle(NewBlockScreenTokens.muted)` exactly as-is — this verbatim copy is asserted by both `BlockBuilderViewCopyTests` and `NewBlockBuilderFidelityTests` and the typography is the BRU contract.
   - KEEP `.allowsHitTesting(false)` on the placeholder HStack — the overlay should never absorb taps. Taps go to the surrounding ZStack via the new gesture (next bullet).
   - Tie the 2x38 ink cursor `Rectangle()` visibility to focus: render it only when `isNameFocused` is true (so the user gets a clear focus affordance), OR render it always but apply `.opacity(isNameFocused ? 1 : 0.55)` so an unfocused state still hints "this is an input." Pick the visible-only-when-focused variant — it makes the focus state unmistakable. Importantly: this means when blank-and-unfocused, the row shows just "NAME YOUR BLOCK" in muted display type (still reads as a prompt), and when blank-and-focused, the ink cursor appears next to it.

4. On the ZStack(alignment: .leading) wrapping the TextField + placeholder (currently lines 281-302):
   - Add `.contentShape(Rectangle())` immediately before any gesture so the entire ZStack frame is the hit area, not just the rendered glyphs.
   - Add `.onTapGesture { isNameFocused = true }` so a tap anywhere in the name row focuses the field.

5. Do NOT change any layout token, no change to `NewBlockScreenTokens.nameBandHeight`, no change to `.padding(.horizontal, NewBlockScreenTokens.sidePadding)`, no change to the preset rows (`presetRows`) or the active chips row (`activeChips`). The "BLOCK NAME" label row above the ZStack is unchanged.

6. Do NOT widen the tap gesture to the entire 152pt band — limit it to the ZStack containing the TextField + placeholder. The preset chip buttons below must still receive their own taps (they are inside the same VStack but outside the ZStack we're modifying).

Constraints:

- Do NOT add any new imports.

- Do NOT touch any other view in this file (NewBlockTopBar, NewBlockMetricsBand, etc.).
