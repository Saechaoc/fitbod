05 / Retained decisions

Product behavior

Four tabs: Today, Program, Progress, Library. Settings is a Today sheet. Tabs hide in the logger and during keyboard entry. History opens from Today Sessions or Progress Workouts.

Signal CTA text is black for contrast. Inert Settings rows were removed. Per week is observed frequency. Summary has one bottom Done. Resume-slab discard confirms when completed sets exist; logger discard always confirms.

Repository provenance

SchemaV7 is the sole baseline; incompatible stores are preserved, not migrated. The prior schema history is on archive/frozen-schema-history. PR #1 was recorded through an ours merge and only its CI workflow was ported.

Prepared commits contain exact task-owned paths, without a Co-Authored-By trailer. Unrelated planning, design exports and tooling stay excluded. Existing main CI triggers do not automatically cover a main push.

Portable report: the Lavish preview server could not start. Static assets and script syntax were checked; live browser layout remains unverified.
