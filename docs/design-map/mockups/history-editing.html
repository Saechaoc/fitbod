Based on workout-summary (header, title block, EXERCISES head, exercise rows), logger and logger--set-logged (S / WEIGHT / REPS / RPE set grid), and the CANCEL / title / SAVE header of workout-notes.

Way in: History, a workout row, then EDIT on the Summary header (right slot, empty today). Way out: SAVE writes the changes and returns to the Summary; CANCEL returns without them, asking first if anything changed.

Date and Start open a date picker and a time picker; they set when the workout happened.

Each weight, reps and RPE cell is a number field; RPE opens the decimal RPE picker. A changed cell gets a 2pt ink border and a "Was" line with the logged value.

− deletes that set at once (SAVE or CANCEL decides). + Add set appends a set copied from the last one.

Delete workout opens a confirmation dialog, then returns to History.
