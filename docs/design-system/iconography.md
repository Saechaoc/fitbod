# Iconography

BRU uses no SF Symbols and no icon images inside the app.
Typographic glyphs set in the BRU faces do the job, so icons share the weight and color of the text around them.

## Glyphs

| Glyph | Meaning | Example |
| --- | --- | --- |
| ‹ | Back | Header "‹ Back" |
| › | Opens a detail screen | Settings rows, list disclosure |
| ▸ | Forward, or the primary action | "Start workout ▸", "Log set ▸" |
| ↘ | Comes from somewhere else | "↘ From library" on add slots |
| + and − | Add or increase, remove or decrease | Steppers, "+ New routine" |
| × | Times, as in sets × reps | "3 × 8" |
| ↑ and ↓ | Trend up or down | Stat readouts, PR deltas |
| ✓ | Done | Completed state labels |
| ● and • | Status dot, list bullet | Trained and not-trained markers |
| ▾ and ▴ | Expand or collapse | Disclosure rows |
| · | Separator between facts | "Version 1.0 · Schema V7" |

The tab bar keeps a glyph per tab (`BRUTab.glyph`: ▣ ▤ ▦ ▥) for reuse, but the bar shows labels only.

## Rules

- A glyph next to a word is decoration: VoiceOver reads the word. Hide a standalone glyph from VoiceOver or give its button a word label, as `BRUHeaderBar` does with "‹ Back" (read as "Back").
- Use the true minus sign (−, U+2212) in steppers so it matches the plus sign's width.
- Glyphs take the color of their text. Signal-colored glyphs follow the accent rules in [principles.md](principles.md).

## App icon

The app icon lives in `fitbod/Assets.xcassets/AppIcon.appiconset/`.
It is generated by `scripts/generate_app_icon.swift`, so change the script and rerun it rather than editing the PNG.
The mark uses the bundled Bebas Neue BRU wordmark, a barbell, an orange bracket
and a square ink panel on warm paper. It replaces the generic teal “F”. iOS
applies the outer icon mask. Regenerate from the repository root:

```sh
swift scripts/generate_app_icon.swift fitbod/Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png
```
